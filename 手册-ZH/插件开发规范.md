## 概述

ArcUI 插件是位于 `plugins/` 目录下的独立文件夹。每个插件通过以下方式扩展 ArcUI：

- **前端 UI 与逻辑** — 通过钩子注册注入到聊天界面
- **Python 能力** — 由 ArcUI 后端执行的服务器端处理

插件当前不在沙箱中运行（原型阶段）。插件开发者受信任 — 安装前请审查插件代码。

### 插件能力一览

| 能力 | 位置 | 示例 |
|------|------|------|
| 发送前修改 | `plugin.js` 钩子 `message.beforeSend` | 附加上下文、转换查询 |
| 响应后处理 | `plugin.js` 钩子 `message.afterReceive` | 记录分析、触发通知 |
| 注入 UI 元素 | `plugin.js` 钩子 `message.render` | 添加音频条、操作按钮 |
| 添加消息操作 | `plugin.js` 钩子 `message.action` | 朗读、复制、翻译按钮 |
| 服务器端处理 | `capability.py` async 函数 | TTS 合成、图片生成 |
| 自定义 API 调用 | `context.fetch()` 通过代理 | 调用第三方服务 |
| 配置项 | `plugin.json` `configSchema` | 设置面板中用户可编辑的配置 |

## 插件文件结构

每个插件位于自己的文件夹中：

```
plugins/{插件ID}/
├── plugin.json       # 必需：元信息 + 配置表单定义
├── plugin.js         # 必需：前端类
└── capability.py     # 可选：Python 函数
```

### 命名规范

- `{插件ID}` 必须为小写字母数字加连字符：`arcui-tts`、`my-translator`、`code-runner`
- 建议以描述性前缀开头（如官方插件使用 `arcui-`）

## plugin.json — 元信息与配置表单定义

### 完整 Schema

```json
{
  "id": "arcui-tts",
  "name": "语音合成",
  "name_en": "TTS",
  "version": "1.0.0",
  "author": "ArcUI",
  "description": "将 AI 回复转为语音播放",
  "description_en": "Convert AI responses to speech",
  "hooks": ["message.action", "message.render"],
  "pythonCapabilities": ["tts_speak", "tts_fetch_voices"],
  "configSchema": [
    {
      "key": "apiEndpoint",
      "label": "TTS API 地址",
      "label_en": "TTS API Endpoint",
      "type": "text",
      "placeholder": "https://api.openai.com/v1/audio/speech",
      "required": false
    },
    {
      "key": "voice",
      "label": "语音",
      "label_en": "Voice",
      "type": "select",
      "options": [
        {"value": "alloy", "label": "Alloy"},
        {"value": "echo", "label": "Echo"}
      ],
      "default": "alloy"
    },
    {
      "key": "autoPlay",
      "label": "自动播放",
      "label_en": "Auto Play",
      "type": "toggle",
      "default": false
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `id` | string | ✅ | 唯一插件标识符 |
| `name` | string | ✅ | 显示名称（中文） |
| `name_en` | string | ✅ | 显示名称（英文） |
| `version` | string | ✅ | 语义化版本号 |
| `author` | string | ✅ | 作者名称 |
| `description` | string | ✅ | 简短描述（中文） |
| `description_en` | string | ✅ | 简短描述（英文） |
| `hooks` | string[] | ❌ | 本插件注册的钩子名称列表 |
| `pythonCapabilities` | string[] | ❌ | `capability.py` 中暴露的 Python 函数名 |
| `configSchema` | object[] | ❌ | 用户可配置的设置项 |

### configSchema 配置项类型

| `type` | 渲染为 | 额外字段 |
|--------|--------|---------|
| `"text"` | 文本输入框 | `placeholder`、`required` |
| `"select"` | 下拉选择 | `options: [{value, label}]`、`default` |
| `"toggle"` | 开关 | `default`（布尔值） |
| `"number"` | 数字输入 | `min`、`max`、`default` |

## plugin.js — 前端逻辑

### 类契约

每个 `plugin.js` 必须导出一个包含以下结构的类：

```javascript
class PluginClass {
  // 静态元信息（对应 plugin.json）
  static meta = {
    id: 'arcui-tts',
    name: 'TTS',
    version: '1.0.0',
  };

  // 构造函数接收沙箱 context
  constructor(context) {
    this.context = context;
  }

  // 初始化：构造后调用一次，接收用户配置
  async init(config) {
    // config = plugin.json configSchema 默认值 + 用户覆盖值合并后的结果
    this.config = config;
  }

  // 向 PluginManager 注册钩子
  registerHooks(registry) {
    // registry.on('钩子名', 回调函数)
  }

  // 插件禁用或卸载时的清理工作
  destroy() {
    // 移除 DOM 元素、事件监听等
  }
}
```

### 最小示例

```javascript
class MinimalPlugin {
  static meta = { id: 'my-plugin', name: 'My Plugin', version: '1.0.0' };

  constructor(context) { this.ctx = context; }
  async init(config) { this.config = config; }
  registerHooks(registry) {
    registry.on('message.afterReceive', (data) => {
      console.log('收到回复:', data.response);
    });
  }
  destroy() {}
}
```

## capability.py — Python 能力

### 规则

1. **所有不以 `_` 开头的顶级 `async` 函数** 自动暴露为能力。
2. 函数签名可包含 `api_key` — 引擎会自动从全局配置注入。
3. 返回值经过 JSON 序列化后发送回前端。
4. 抛出异常即表示错误 — 引擎会捕获并返回 `{error: "消息"}`。

### 示例

```python
# capability.py
import aiohttp

async def tts_speak(text: str, voice: str, api_key: str = "") -> dict:
    """
    调用 TTS API 并返回 base64 音频。
    api_key 自动从 ArcUI 配置注入。
    """
    if not api_key:
        raise ValueError("API key 未配置")

    async with aiohttp.ClientSession() as session:
        async with session.post(
            "https://api.openai.com/v1/audio/speech",
            headers={"Authorization": f"Bearer {api_key}"},
            json={
                "model": "tts-1",
                "input": text,
                "voice": voice,
                "response_format": "mp3",
            },
        ) as resp:
            audio_bytes = await resp.read()
            import base64
            return {"audio_base64": base64.b64encode(audio_bytes).decode(), "format": "mp3"}


async def tts_fetch_voices(api_key: str = "") -> dict:
    """返回可用语音列表。OpenAI TTS 的静态列表。"""
    return {
        "voices": [
            {"id": "alloy", "name": "Alloy"},
            {"id": "echo", "name": "Echo"},
            {"id": "fable", "name": "Fable"},
            {"id": "onyx", "name": "Onyx"},
            {"id": "nova", "name": "Nova"},
            {"id": "shimmer", "name": "Shimmer"},
        ]
    }
```

### 从 plugin.js 调用

```javascript
// 在 plugin.js 中，使用沙箱 context：
const result = await this.context.callPython('tts_speak', {
  text: '你好世界',
  voice: 'alloy',
});
// result = { audio_base64: "...", format: "mp3" }
```

## 沙箱 Context API

传递给插件构造函数的 `context` 对象提供以下能力：

### `context.fetch(url, options?)`

通过 ArcUI 后端代理 HTTP 请求。返回标准 `Response` 对象。

```javascript
const response = await this.context.fetch('https://api.example.com/data', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ key: 'value' }),
});
const data = await response.json();
```

**为什么需要代理？** 避免 CORS 问题，并将 API Key 保留在服务端。所有请求通过 ArcUI 后端的 `POST /api/proxy` 路由。

### `context.callPython(capability, params)`

执行 `capability.py` 中的 Python 能力函数。

```javascript
const result = await this.context.callPython('tts_speak', {
  text: '要朗读的文本',
  voice: 'alloy',
});
// result 是 Python 函数的 JSON 返回值
```

### `context.audio`

音频播放工具：

```javascript
// 播放 base64 编码的音频
this.context.audio.playFromBase64('base64字符串...');

// 播放 Blob
this.context.audio.playBlob(audioBlob);

// 使用浏览器语音合成
this.context.audio.speakBrowser('要朗读的文本');
```

### `context.storage`

插件级别的持久化存储（localStorage）：

```javascript
this.context.storage.set('myKey', { some: 'data' });
const value = this.context.storage.get('myKey'); // { some: 'data' }
this.context.storage.remove('myKey');
```

Key 按插件隔离（自动添加插件 ID 前缀），插件 A 的 `storage.set('x', 1)` 不会与插件 B 冲突。

### `context.notify(message, type?)`

显示 Toast 通知：

```javascript
this.context.notify('操作完成');           // 普通提示
this.context.notify('操作失败', 'error');  // 错误提示
```

### `context.getLanguage()`

返回当前 UI 语言：`'zh'` 或 `'en'`。

### `context.getConfig()`

返回全局 ArcUI 配置对象（Base URL 等）。**注意：** API Key 已脱敏。

### `context.on(event, callback)` / `context.emit(event, data)`

插件间通信：

```javascript
// 插件 A 发送事件
this.context.emit('自定义事件', { value: 42 });

// 插件 B 监听事件
this.context.on('自定义事件', (data) => {
  console.log(data.value); // 42
});
```

## 钩子参考

所有钩子通过 `registerHooks()` 中的 `registry.on(钩子名, 回调)` 注册。

### `message.beforeSend`

**触发时机：** 用户消息即将发送给 LLM 之前。

**回调签名：** `function(data) → modifiedMessages`

```javascript
// data = { query: string, messages: array, config: object }
// 必须返回（可能已修改的）messages 数组

registry.on('message.beforeSend', (data) => {
  // 在开头添加额外上下文
  data.messages.unshift({
    role: 'system',
    content: '来自插件的额外上下文',
  });
  return data.messages;
});
```

### `message.afterReceive`

**触发时机：** 完整响应从 LLM 接收后。

**回调签名：** `function(data) → void`

```javascript
// data = { response: string, rawData: object, isFactARC: boolean }

registry.on('message.afterReceive', (data) => {
  // 记录分析
  console.log('响应长度:', data.response.length);
  // 触发自定义处理
  this.context.emit('response-ready', data);
});
```

### `message.render`

**触发时机：** 消息 DOM 元素创建/更新时。

**回调签名：** `function(message, domElement) → void`

```javascript
// message = { role, content, timestamp, ... }
// domElement = 消息对应的 <div class="message"> 元素

registry.on('message.render', (message, domElement) => {
  if (message.role === 'assistant') {
    // 在底部注入自定义 UI
    const button = document.createElement('button');
    button.textContent = '自定义操作';
    domElement.querySelector('.message-content').appendChild(button);
  }
});
```

### `message.action`

**触发时机：** 构建消息操作按钮列表时。

**回调签名：** `function(message, actions[]) → actions[]`

```javascript
// actions = [{ id, label, label_en, onClick }]

registry.on('message.action', (message, actions) => {
  if (message.role === 'assistant') {
    actions.push({
      id: 'tts-speak',
      label: '语音播放',
      label_en: 'Speak',
      onClick: () => this.speak(message.content),
    });
  }
  return actions;
});
```

### `chat.header`

**触发时机：** 对话头部渲染时。

**回调签名：** `function(chatInfo) → void`

```javascript
// chatInfo = { id, title, timestamp }

registry.on('chat.header', (chatInfo) => {
  // 向对话头部添加状态指示器
});
```

### `sidebar.item`

**触发时机：** 侧边栏对话项渲染时。

**回调签名：** `function(chatItem) → void`

```javascript
// chatItem = { id, title, timestamp, domElement }

registry.on('sidebar.item', (chatItem) => {
  // 为某些对话添加徽章
});
```

### `api.provider`

**触发时机：** API 提供商注册时。

**回调签名：** `function(providers[]) → providers[]`

```javascript
// providers = [{ name, baseUrl }]

registry.on('api.provider', (providers) => {
  providers.push({ name: '我的提供商', baseUrl: 'https://my.api.com/v1' });
  return providers;
});
```

## 插件生命周期

```
  检测到插件文件夹
         │
         ▼
  解析 plugin.json
         │
         ▼
  加载 configSchema 默认值
  合并用户覆盖值
         │
         ▼
  实例化 PluginClass(context)
         │
         ▼
  await plugin.init(config)
         │
         ▼
  plugin.registerHooks(registry)
         │
         ▼
  [ 插件激活 — 钩子响应事件触发 ]
         │
         ▼
  用户禁用 / 卸载插件
         │
         ▼
  plugin.destroy()
         │
         ▼
  插件移除
```

### 启用/禁用

用户在 **设置 → 插件** 中管理插件：
- 开关启用/禁用
- 配置设置项（由 `configSchema` 生成表单）
- 粘贴插件文件夹手动安装

### plugins/tts/plugin.js

```javascript
class TTSPlugin {
  static meta = { id: 'arcui-tts', name: 'TTS', version: '1.0.0' };

  constructor(context) {
    this.ctx = context;
    this.audioEl = null;
  }

  async init(config) {
    this.config = config;
  }

  registerHooks(registry) {
    // 为每条助手消息添加"播放"按钮
    registry.on('message.action', (message, actions) => {
      if (message.role === 'assistant' && message.content) {
        actions.push({
          id: 'tts-speak',
          label: '播放',
          label_en: 'Speak',
          onClick: () => this.speak(message.content),
        });
      }
      return actions;
    });

    // 注入音频进度条
    registry.on('message.render', (message, domElement) => {
      if (message.role === 'assistant') {
        this.injectAudioBar(domElement);
      }
    });

    // 若开启自动播放则自动朗读
    registry.on('message.afterReceive', async (data) => {
      if (this.config.autoPlay) {
        await this.speak(data.response);
      }
    });
  }

  async speak(text) {
    const lang = this.ctx.getLanguage();
    try {
      if (this.config.apiEndpoint) {
        // 通过 Python 能力使用 TTS API
        const result = await this.ctx.callPython('tts_speak', {
          text,
          voice: this.config.voice || 'alloy',
        });
        if (result.audio_base64) {
          this.ctx.audio.playFromBase64(result.audio_base64);
          return;
        }
      }
    } catch (e) {
      this.ctx.notify('TTS API 失败，使用浏览器引擎', 'error');
    }
    // 回退到浏览器语音合成
    this.ctx.audio.speakBrowser(text);
  }

  injectAudioBar(domElement) {
    const bar = document.createElement('div');
    bar.className = 'audio-bar';
    bar.innerHTML = '<button>▶ 播放</button><div class="progress"></div><span>0:00</span>';
    domElement.appendChild(bar);
  }

  destroy() {
    // 清理音频元素
  }
}
```

"""ArcUI TTS 插件的能力函数。"""
import aiohttp
import base64


async def tts_speak(text: str, voice: str = "alloy", api_key: str = "") -> dict:
    """通过 OpenAI TTS API 生成语音。"""
    if not api_key:
        raise ValueError("API key 未配置")

    async with aiohttp.ClientSession() as session:
        async with session.post(
            "https://api.openai.com/v1/audio/speech",
            headers={
                "Authorization": f"Bearer {api_key}",
                "Content-Type": "application/json",
            },
            json={
                "model": "tts-1",
                "input": text,
                "voice": voice,
                "response_format": "mp3",
            },
        ) as resp:
            if resp.status != 200:
                error = await resp.text()
                raise Exception(f"TTS API 错误: {error}")
            audio_bytes = await resp.read()
            return {
                "audio_base64": base64.b64encode(audio_bytes).decode("utf-8"),
                "format": "mp3",
            }


async def tts_fetch_voices(api_key: str = "") -> dict:

    return {

## 最佳实践

### 1. 命名空间化你的 ID
使用唯一前缀：`arcui-`、`mycompany-` 等。

### 2. 始终实现 `destroy()`
清理 DOM 元素、事件监听、定时器和音频对象，防止内存泄漏。

### 3. 保持 plugin.js 轻量
将重量级处理通过 `context.callPython()` 卸载到 `capability.py`。

### 4. 优雅处理错误
```javascript
async speak(text) {
  try {
    const result = await this.ctx.callPython('tts_speak', { text });
    // ...
  } catch (e) {
    this.ctx.notify('播放失败: ' + e.message, 'error');
  }
}
```

### 5. 尊重语言设置
使用 `context.getLanguage()` 本地化界面文案：

```javascript
const label = this.ctx.getLanguage() === 'zh' ? '播放' : 'Play';
```

### 6. 使用 CSS 变量
如果插件注入带样式的 DOM 元素，请使用 ArcUI CSS 变量以保持主题一致性：

```css
.my-plugin-button {
  background: var(--bg-elevated);
  color: var(--text-primary);
  border: 1px solid var(--border-default);
}
```

### 7. 在有/无 Fact-ARC 的情况下测试
你的插件无论在有无 Fact-ARC 后端的情况下都应正常工作。

### 8. 完善 configSchema 文档
每个配置字段应有清晰的 `label` 和 `label_en`。

1. 将插件文件夹打包为 zip
