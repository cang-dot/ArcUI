欢迎使用 ArcUI
通用的 AI 对话前端。配置 LLM API 即可开始。
Ctrl+N 新对话

设置

API 配置
配置 LLM API 地址和密钥。支持任何 OpenAI 兼容 API。
Bocha API 密钥，用于联网搜索功能。留空则不启用。
纠错引擎 ※
发送后 LLM 自我审查并自动迭代修正回答中的错误。结果不满意时建议开启。

△ 开了纠错后，会说一些"官方话"；未联网时，联网纠错功能可能不能正常工作。

系统提示词
自定义发送给模型的系统提示词。留空使用默认。
可用变量：{{model}} {{date}} {{user_name}}
TTS 语音设置
配置文字转语音。不填则使用浏览器内置引擎。
插件管理
管理已安装的插件。
