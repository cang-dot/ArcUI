## 快速入门

### 前置条件

- 一个 OpenAI 兼容 LLM 服务的 API Key（如 OpenAI、DeepSeek 等）
- Python 3.9+ 及 pip

### 安装步骤

1. **安装依赖**
   ```bash
   cd ArcUI/backend
   pip install -r requirements.txt
   ```

2. **启动后端**
   ```bash
   python server.py
   ```
   ArcUI 后端运行在 `http://localhost:1011`。

3. **打开前端**
   在浏览器中打开 `index.html`。推荐使用 Chrome、Edge 或 Firefox。

4. **配置 API**
   - 首次启动会显示配置界面。
   - 输入你的 **Base URL**（例如 `https://api.openai.com/v1` 或 `https://api.deepseek.com/v1`）。
   - 输入你的 **API Key**。
   - 点击 **测试连接** 验证，然后点击 **保存**。

5. **开始聊天**
   配置保存后输入区域即出现。从下拉栏中选择模型，输入第一条消息即可开始对话。

### 顶栏
- **☰（汉堡菜单）** — 切换侧边栏显示/隐藏
- **ArcUI** — 应用名称
- **中文/EN** — 切换语言
- **◐** — 切换暗色/浅色主题
- **⚙** — 打开设置

### 侧边栏
- **+ 新对话** — 开始新对话
- **搜索框** — 按标题/内容过滤对话
- **对话列表** — 点击切换；高亮项为当前对话

- **消息区** — 可滚动的聊天记录
- **输入区** — 文本输入框，上方为多模态工具栏
- **模型下拉栏** — 随时切换模型
- **纠错轮次** — 自我纠错回合数（适用于支持的后端）

## 聊天操作

### 发送消息
- 在输入框中输入文字，按 **Enter** 发送（或点击 **↑** 按钮）
- 使用 **Shift+Enter** 在消息中插入换行
- 正在生成回复时，发送按钮禁用

### 流式输出
- 回复实时流式显示，打字机效果
- 输出中末尾显示闪烁光标
- 点击 **■（停止）** 可中断生成

### 代码块
- 代码块有语法高亮和深色背景
- 流式输出时，未闭合的代码块先显示为纯文本，闭合后自动格式化

### 每条消息的操作按钮
每条助手消息底部可显示操作按钮：
- **TTS 播放** — 朗读该消息内容

## 多模态（图片与音频）

### 工作原理
ArcUI 自动检测当前选中的模型是否支持视觉和/或音频能力。当模型支持图片时，输入框上方会显示多模态工具栏。

### 上传图片
- **点击 📎** — 打开文件选择器
- **拖放** — 将图片拖入聊天区域
- **剪贴板粘贴** — Ctrl+V 粘贴剪贴板中的图片

### 管理附件
- 缩略图显示在输入框上方的工具栏中
- 点击缩略图可 **删除** 附件
- 所有附件随下一条消息一起发送

### 图片处理
- 图片在发送前缩放至最大 2048px 宽度（由后端处理）
- 以 `content` 数组形式发送：`[{type:"image_url", image_url:{url:"data:image/..."}}, {type:"text", text:"..."}]`

### 音频（预留）
音频录制功能保留给未来版本。

## 设置面板

通过顶栏的 ⚙ 按钮打开设置。

### API 配置
| 字段 | 说明 |
|------|------|
| **Base URL** | LLM API 端点（例如 `https://api.openai.com/v1`） |
| **API Key** | 你的密钥。存储在 localStorage 中，不会发送给第三方 |
| **ArcUI 后端 URL** | 默认 `http://localhost:1011`。如果后端部署在其他地址，请修改 |

- 点击 **测试连接** 验证 API 是否可达
- 点击 **保存** 持久化

### 系统提示词
自定义发送给模型的系统提示词。留空则使用当前语言的默认值。

**可用变量：**
- `{{model}}` — 替换为当前模型名
- `{{date}}` — 替换为当前日期（YYYY-MM-DD）
- `{{user_name}}` — 替换为你配置的用户名（默认 "User"）

点击 **恢复默认** 重置为默认提示词。

### TTS 设置
| 字段 | 说明 |
|------|------|
| **TTS API 地址** | TTS API 的 URL。留空则默认使用 OpenAI TTS |
| **语音** | 语音选择（Alloy、Echo、Fable、Onyx、Nova、Shimmer） |
| **自动播放** | 自动朗读助手回复 |

如果未配置 TTS API，ArcUI 会回退到浏览器的内置语音合成。

### 外观
- **主题** — 暗色或浅色
- **语言** — 中文或 English

两项设置均持久化，下次访问时自动恢复。

### 危险区域
- **清除全部** — 移除所有已保存的配置、聊天记录和系统提示词。请谨慎使用。

## 模型切换

模型下拉栏位于聊天输入框下方。保存 API 配置后：

1. ArcUI 从 API 的 `/models` 端点获取可用模型列表
2. 下拉栏自动填充
3. 选择任意模型即可切换
4. 切换后自动重新检测多模态能力

如果模型列表获取失败，你仍然可以在下拉栏中手动输入模型名称。

## 系统提示词

### 默认提示词

| 语言 | 默认内容 |
|------|---------|
| 中文 | 你是一个知识渊博、乐于助人的AI助手。请用中文回答用户的问题。回答应准确、清晰、有条理。 |
| English | You are a knowledgeable and helpful AI assistant. Provide accurate, clear, and well-structured responses. |

### 自定义提示词流程
1. 在 **设置 → 系统提示词** 中编辑
2. 点击 **保存**（或 **保存提示词**）
3. 每次请求时作为 `system` 角色消息发送

## TTS（文字转语音）

### 音频条
每条助手消息底部会显示音频条：

```
[▶ 播放] [━━━━━━━━━━] 0:32
```

- **▶ 播放** — 将消息朗读为语音
- **进度条** — 可视化播放进度
- **时长** — 预计朗读时间

### 播放优先级
1. 已配置的 TTS API（OpenAI TTS 或兼容）
2. 浏览器的 `window.speechSynthesis` 回退

### 语言
浏览器引擎会根据内容自动检测并使用相应语言朗读。

## 验证轨迹（Fact-ARC）

当 ArcUI 检测到 [Fact-ARC](https://github.com/cang-dot/Fact-ARC) 后端时：

1. 从 `/api/identity` 获取令牌
2. 所有请求携带 `X-FactARC-Token` 头
3. 响应中可能包含 `verification_trail` 数据
4. 验证轨迹在助手消息下方以可展开区域展示，显示事实核查步骤和来源

如果未检测到 Fact-ARC 后端，所有功能仍正常工作 — 仅不显示验证轨迹。

## 常见问题排查

### "请先配置 API"
打开设置 → 填入 Base URL 和 API Key → 保存。

### 下拉栏中没有模型
- 确认 Base URL 是否正确
- 点击 **测试连接** 验证
- 确保你的 API Key 有列出模型的权限（`/models` 端点）

### 流式输出中断或卡住
- 点击 **■（停止）** 中止后重试
- 检查网络连接
- 某些代理可能缓存 SSE；尝试直连

### 图片无法上传
- 确认所选模型支持视觉（模型名包含 `vision`、`vl`、`gpt-4o` 等关键词）
- 多模态工具栏仅对支持视觉的模型显示
- 支持格式：JPEG、PNG、WebP、GIF

### TTS 不工作
- 未配置 API 端点时，ArcUI 使用浏览器引擎
- Chrome/Edge 的语音合成支持最好
- Firefox/Safari 的语音选项可能有限

### 后端无法启动
- 确认 Python 3.9+ 已安装：`python --version`
- 安装依赖：`pip install -r requirements.txt`
- 检查端口 1011 未被占用：`netstat -ano | findstr 1011`
